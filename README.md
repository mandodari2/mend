mend applies an edit that an AI model wrote to a tree of text files, in all four formats: unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON. Every file is changed or nothing is.

## Run it

```sh
node main.ts [options] [PATCH]
```
